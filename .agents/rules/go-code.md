# Go code

Prefix: GO.

- **GO1:** The library imports the standard library and `github.com/psyb0t/ctxerrors`, nothing else. `depguard` in `.golangci.yml` allows `$gostd`, `github.com/psyb0t`, testify, logrus and `github.com/pkg/errors`; the last two are not used and are no reason to start. A new third-party dependency needs a reason that outweighs adding it to every importer's module graph.
- **GO2:** `make lint` must pass with zero issues: it fails on any `go fix -diff` output and then runs golangci-lint with `.golangci.yml`. Fix the code rather than adding `//nolint`. The existing `//nolint` comments (`gochecknoglobals` and `gochecknoinits` on the global state, `exhaustive` on the kind switches) each name the linter they silence; a new one does the same.
- **GO3:** Test files are excluded from golangci-lint in `.golangci.yml`, so keep them readable by hand: testify `require`, table-driven cases where they fit.
- **GO4:** `vendor/` is generated by `make dep`. Never edit it. After changing `go.mod`, run `make dep` and commit `go.mod`, `go.sum` and `vendor/` together.
- **GO5:** Reflection setters write through `reflect.Value.Set*`. A field must be exported for that to work; an unexported field with an `env` tag panics as soon as a value is applied to it. Keep any new setter on the same path so the behavior stays the same for every type.
